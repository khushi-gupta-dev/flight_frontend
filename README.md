# SkyLink Frontend

React 19 and Vite client for flight search, authentication, booking, customer booking history/profile, and admin flight/booking tools. Routes are defined in `src/App.jsx`; API requests use the gateway and optionally `VITE_API_BASE_URL`.

## Run

```sh
npm install
npm run dev
```

Check with `npm run lint` and `npm run build`. Login, booking, and admin operations require the API Gateway and relevant backend services to be running.
